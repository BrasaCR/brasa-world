# BRASA 세계

**교육, 정부 서비스, 비즈니스, 공공 투명성을 연결하여 모든 시민을 위해 만든 시스템입니다.**

[BRASA 세계 방문](https://brasa.world/) · [교육](https://brasa.education/) · [정부 서비스](https://brasagovernment.net/) · [비즈니스](https://brasa.business/)

BRASA는 세계 시스템을 운영하는 영어 원문을 바꾸지 않으면서 공공 지식, 시민 서비스, 교육, 상거래를 연결합니다. 국가별 페이지는 방문자를 거주 지역과 관련된 기관, 학교, 서비스, 사업체로 안내합니다.

## 네 가지 기둥

- **교육:** 학교, 대학, 강좌, 평생 학습 기회를 찾습니다.
- **정부 서비스:** 부처, 공공 기관, 공공서비스 제공자, 시민 서비스에 접근합니다.
- **비즈니스:** 시민이 사업을 시작하고 운영하며 성장시키는 무료 도구입니다.
- **BRASA:** 국가에 맞게 구성되어 전체 시스템을 연결하는 공공 진입점입니다.

## 국가별 구축

BRASA는 지원하는 각 국가에 독립적인 국가 페이지를 유지합니다. 모든 페이지는 공통 세계 디자인을 사용하면서 해당 국가의 실제 정부 기관, 교육 자원, 서비스로 연결됩니다.

## 언어 접근

영어는 BRASA가 유지하는 원문 언어입니다. 방문자는 현지화 버전을 이용하고 편집자는 동일한 영어 기준으로 계속 작업할 수 있습니다. 게시된 번역마다 고유 주소, 언어 메타데이터, 검토 상태, 영어 버전 링크가 있습니다.

## 여기에서 시작

[brasa.world](https://brasa.world/)에서 국가, 언어 또는 기둥을 선택하세요.

## 참여하기

국가 정보 확인, 번역 검토, 오래된 공공 링크 신고, 접근성 개선에 참여해 주세요. 번역 수보다 정확성과 유용한 지역 정보를 우선합니다.

## 오늘의 BRASA

BRASA는 이제 198개 국가 목적지를 교육, 정부, 비즈니스와 연결합니다. BRASA Business에는 판매와 영수증, CRM, 재고, 인사와 교육, 급여와 금융, 시간 관리, 가족 지원, 법무, 정부 양식, 보고서, 공동 작업 공간 등 12개의 연결된 운영 영역이 있습니다. 오픈 원장, 안내형 업무 흐름, 오프라인 연속 운영도 포함됩니다.

BRASA Financials는 395개 기록에서 385개 결제 시스템을 정리했으며, 161개 국가 또는 다국가 시장 설명과 216개 결제 유형을 포함합니다. 모바일 머니, 즉시 이체, QR, 지갑, 현금 네트워크, 송금, 오픈뱅킹, 국내 카드 시스템, USSD 등이 포함됩니다.

목록에 있다는 것은 활성화되었다는 뜻이 아닙니다. 자금은 인가된 제공업체가 이동하며, 각 방식은 국가와 공식 출처 검토, 인허가, 연동, 정산 시험, 운영 승인을 거쳐야 합니다. BRASA는 검증된 선택지를 영수증, 대사, 오픈 원장에 연결합니다.
