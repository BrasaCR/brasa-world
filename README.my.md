# BRASA World

**ပညာရေး၊ အစိုးရ၊ စီးပွားရေးနှင့် အများပြည်သူ ပွင့်လင်းမြင်သာမှုအတွက် ချိတ်ဆက်ထားသော စနစ်တစ်ခု— နိုင်ငံသားတိုင်းအတွက် တည်ဆောက်ထားသည်။**

[BRASA World သို့သွားပါ။](https://brasa.world/) · [ပညာရေး](https://brasa.education/) · [အစိုးရ](https://brasagovernment.net/) · [စီးပွားရေး](https://brasa.business/)

BRASA သည် အများသူငှာ အသိပညာ၊ နိုင်ငံသားဝန်ဆောင်မှုများ၊ ပညာရေးနှင့် ကူးသန်းရောင်းဝယ်ရေးတို့ကို ကမ္ဘာလုံးဆိုင်ရာစနစ်ကို အားကောင်းစေသော အင်္ဂလိပ်အရင်းအမြစ်ကို မပြောင်းလဲဘဲ ချိတ်ဆက်ပေးပါသည်။ နိုင်ငံအလိုက် စာမျက်နှာများသည် ဧည့်သည်တစ်ဦးစီအား ၎င်းတို့နေထိုင်ရာနှင့် သက်ဆိုင်သည့် အဖွဲ့အစည်းများ၊ ကျောင်းများ၊ ဝန်ဆောင်မှုများနှင့် စီးပွားရေးလုပ်ငန်းများကို လမ်းညွှန်ပေးသည်။

## လေးတိုင်

- **ပညာရေး-** ကျောင်းများ၊ တက္ကသိုလ်များ၊ သင်တန်းများနှင့် တစ်သက်တာသင်ယူမှုကို ရှာဖွေပါ။
- **အစိုးရ-** ဝန်ကြီးဌာနများ၊ အစိုးရအဖွဲ့အစည်းများ၊ အသုံးဝင်မှုများနှင့် နိုင်ငံသားဝန်ဆောင်မှုများကို လမ်းညွှန်ပါ။
- **စီးပွားရေး-** နိုင်ငံသားများအတွက် လုပ်ငန်းစတင်ရန်၊ လုပ်ငန်းလည်ပတ်ရန်နှင့် ကြီးထွားရန်အတွက် အခမဲ့ကိရိယာများ။
- **BRASA-** စနစ် အပြည့်အစုံကို ချိတ်ဆက်ပေးသည့် နိုင်ငံ-သတိပြုမိသော အများသူငှာ ဝင်ပေါက်။

## နိုင်ငံအလိုက် ဆောက်တယ်။

BRASA သည် ပံ့ပိုးပေးထားသော နိုင်ငံတိုင်းအတွက် နိုင်ငံတစ်နိုင်ငံစာမျက်နှာကို ထိန်းသိမ်းထားသည်။ စာမျက်နှာတစ်ခုစီသည် ထိုနိုင်ငံ၏ စစ်မှန်သော အစိုးရအဖွဲ့အစည်းများ၊ ပညာရေးအရင်းအမြစ်များနှင့် ဝန်ဆောင်မှုများနှင့် ချိတ်ဆက်နေချိန်တွင် မျှဝေထားသော ကမ္ဘာတစ်ဝှမ်းရှိ ဒီဇိုင်းကို အသုံးပြုပါသည်။

## ဘာသာစကားဝင်ရောက်ခွင့်

အင်္ဂလိပ်သည် BRASA ၏ ထိန်းသိမ်းထားသော မူရင်းဘာသာစကားဖြစ်သည်။ တည်းဖြတ်သူများသည် တူညီသော အင်္ဂလိပ်စံနှုန်းအတိုင်း ဆက်လက်လုပ်ဆောင်နေချိန်တွင် ဧည့်သည်များသည် ဒေသန္တရပုံစံဗားရှင်းကို အသုံးပြုနိုင်သည်။ ထုတ်ဝေထားသော ဘာသာပြန်များသည် ၎င်းတို့၏ ကိုယ်ပိုင် URL၊ ဘာသာစကား မက်တာဒေတာ၊ ပြန်လည်သုံးသပ်မှု အခြေအနေနှင့် အင်္ဂလိပ်သို့ ပြန်လင့်ခ်ကို ရရှိသည်။
