# BRASA World

** Ètò kan tí ó ní ìsopọ̀ fún ẹ̀kọ́, ìjọba, ìṣòwò, àti ìfihàn gbogbo ènìyàn tí a kọ́ fún gbogbo ọmọ ìlú.**

[Lọ sí BRASA World](https://brasa.world/)·[Ẹ̀kọ́](https://brasa.education/)·[Ìjọba](https://brasagovernment.net/)·[Okòwò](https://brasa.business/)

BRASA so ìmọ̀ gbogbo ènìyàn, àwọn iṣẹ́ ìlú, ẹ̀kọ́, àti ìṣòwò láì yí orísun èdè Gẹ̀ẹ́sì tí ó ń fún ètò àgbáyé lókun padà. Àwọn ojúewé orílẹ̀ èdè máa ń tọ́ olúkúlùkù àlejò lọ sí ilé-iṣẹ́, ilé-ìwé, iṣẹ́, àti ilé-iṣẹ́ tí ó bá ibi tí wọ́n ń gbé mu.

## Awọn ọwọn mẹrin

- **Ẹ̀kọ́:** rí ilé-ẹ̀kọ́, ilé-ẹ̀kọ́ gíga, ìdánilẹ́kọ̀ọ́, àti ìkọ́nilẹ́kọ̀ọ́ ayérayé.
- **Ijọba:** lilọ kiri si awọn ẹka, awọn ile-iṣẹ ilu, awọn ohun elo, ati awọn iṣẹ ilu.
- **Iṣowo:** Awọn irinṣẹ ọfẹ fun awọn ara ilu lati bẹrẹ, ṣiṣẹ, ati dagba iṣowo kan.
- **Brasa:** ẹnu-ọna gbangba ti o mọ orilẹ-ede ti o so gbogbo eto naa pọ.

## Ti a kọ orilẹ-ede nipasẹ orilẹ-ede

BRASA máa ń ṣe ojú-ìwé orílẹ̀ èdè fún gbogbo orílẹ̀ èdè tí wọ́n ń tì lẹ́yìn. Ojú-ìwé kọ̀ọ̀kan ń lo àwòrán tí wọ́n pín káàkiri ayé nígbà tí ó ń so mọ́ àwọn ilé-iṣẹ́ ìjọba gidi orílẹ̀-èdè náà, àwọn ohun èlò ẹ̀kọ́, àti àwọn iṣẹ́.

## Èdè ìfikúnsí

Èdè Gẹ̀ẹ́sì ni èdè orísun tí Brasa ń sọ. Àwọn àlejò lè lo ẹ̀dà tí ó wà ní àdúgbò nígbà tí àwọn atúmọ̀ èdè ń bá a lọ láti máa ṣiṣẹ́ láti ìlànà èdè Gẹ̀ẹ́sì kan náà. Àwọn ìtúmọ̀ tí a tẹ̀ jáde gba URL tiwọn, metadata èdè, ipò àtúnyẹ̀wò, àti ìjápọ padà sí èdè Gẹ̀ẹ́sì.

## Bẹ̀rẹ̀ níbí

Abẹwo[brasa.world](https://brasa.world/)kí o sì yan orílẹ̀-èdè rẹ, èdè rẹ, tàbí ọ̀wọ̀n rẹ.

## Ilowosi

Ran orílẹ̀-èdè kan lọ́wọ́, ṣe àtúnyẹ̀wò ìtúmọ̀ kan, ròyìn àsopọ̀ gbogbo ènìyàn tí ó ti di ìgbà àtijọ́, tàbí ṣe àtúnṣe ìfikúnsí. Ìdánilójú àti àlàyé àdúgbò tó wúlò máa ń dé ṣáájú ìdìpọ̀ ìtúmọ̀.

## BRASA lónìí

BRASA ti so àwọn ibi orílẹ̀-èdè 198 pọ̀ mọ́ Ẹ̀kọ́, Ìjọba àti Iṣòwò. BRASA Business ní apá 12 tí ó so pọ̀: títà àti risiti, CRM, ọjà inú ilé, ènìyàn àti ìdánilẹ́kọ̀ọ́, owó oṣù àti ilé-ifowopamọ́, àkókò, ìrànlọ́wọ́ ẹbí, iṣẹ́ òfin, fọ́ọ̀mù ìjọba, ìròyìn àti ibi iṣẹ́ àjọṣe. Ó tún ní ìwé ìṣirò ṣíṣi, ìlànà iṣẹ́ tí a darí àti ìtẹ̀síwájú láìsí íńtánẹ́ẹ̀tì.

BRASA Financials ṣe àkójọ àwọn ètò ìsanwó 385 láti inú àkọsílẹ̀ 395, pẹ̀lú àlàyé ọjà 161 àti irú ìsanwó 216: owó alágbèéká, gbigbe lẹ́sẹ̀kẹsẹ̀, QR, àpò owó díjítà, nẹ́tíwọ́ọ̀kì owó, fífi owó ránṣẹ́, open banking, káàdì abẹ́lé àti USSD.

Wíwà nínú àkójọ kò túmọ̀ sí pé a ti mú un ṣiṣẹ́. Àwọn olupèsè tó ní ìwé-àṣẹ ni wọ́n ń gbé owó; ọ̀nà kọ̀ọ̀kan nílò àyẹ̀wò orílẹ̀-èdè àti orísun, ìwé-àṣẹ, ìsopọ̀, ìdánwò ìsanpada àti ìfọwọ́sí iṣẹ́ gidi.
