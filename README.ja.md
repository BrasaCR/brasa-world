# BRASA 世界

**教育、行政サービス、ビジネス、公共の透明性をつなぎ、すべての市民のために構築されたシステムです。**

[BRASA 世界を見る](https://brasa.world/) · [教育](https://brasa.education/) · [行政サービス](https://brasagovernment.net/) · [ビジネス](https://brasa.business/)

BRASA は、世界共通システムを動かす英語の原文を変更せずに、公共知識、市民サービス、教育、商取引をつなぎます。国別ページは、居住地に関係する機関、学校、サービス、事業者へ利用者を案内します。

## 4つの柱

- **教育：**学校、大学、講座、生涯学習の機会を探せます。
- **行政サービス：**省庁、公共機関、公共サービス事業者、市民向けサービスにアクセスできます。
- **ビジネス：**市民が事業を始め、運営し、成長させるための無料ツールです。
- **BRASA：**国ごとに調整され、システム全体をつなぐ公共の入口です。

## 国ごとに構築

BRASA は、対応する各国に専用の国別ページを設けています。各ページは共通の世界デザインを使いながら、その国の実在する政府機関、教育資源、サービスへリンクします。

## 言語での利用

英語は BRASA が維持する原文言語です。利用者はローカライズ版を使い、編集者は同じ英語基準で作業を続けられます。公開された各翻訳には、固有のアドレス、言語メタデータ、確認状況、英語版へのリンクがあります。

## ここから始める

[brasa.world](https://brasa.world/) にアクセスし、国、言語、または柱を選んでください。

## 協力する

国情報の確認、翻訳のレビュー、古い公共リンクの報告、アクセシビリティの改善にご協力ください。翻訳数よりも、正確さと役立つ地域情報を優先します。

## 現在のBRASA

BRASAは現在、198の国別ページを教育・政府・ビジネスと結び付けています。BRASA Businessには、販売時点管理と領収書、CRM、在庫、人材と研修、給与と銀行、時間管理、家族支援、法務、政府書式、レポート、共有ワークスペースという12の連携領域があります。オープン台帳、ガイド付きワークフロー、オフライン継続運用も含まれます。

BRASA Financialsは395件の記録から385の決済システムを整理し、161の国・複数国市場の説明と216の決済種類を収録しています。モバイルマネー、即時振込、QR、ウォレット、現金ネットワーク、送金、オープンバンキング、国内カード、USSDなどが含まれます。

掲載は利用開始や承認を意味しません。資金を移動するのは認可を受けた事業者です。各方式には、国と公式情報源の確認、認可、接続、決済テスト、本番承認が必要です。BRASAは確認済みの選択肢を領収書、照合、オープン台帳につなぎます。
