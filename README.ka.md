# BRASA მსოფლიო

**განათლების, საჯარო მმართველობის, ბიზნესისა და საზოგადოებრივი გამჭვირვალობის ერთიანი დაკავშირებული სისტემა—შექმნილი თითოეული მოქალაქისთვის.**

[ეწვიეთ BRASA მსოფლიოს](https://brasa.world/) · [განათლება](https://brasa.education/) · [საჯარო მმართველობა](https://brasagovernment.net/) · [ბიზნესი](https://brasa.business/)

BRASA აკავშირებს საჯარო ცოდნას, მოქალაქეთა მომსახურებებს, განათლებასა და ვაჭრობას ისე, რომ არ ცვლის გლობალური სისტემის ინგლისურ წყაროს. ქვეყნების გვერდები ვიზიტორებს მათ საცხოვრებელ ადგილთან დაკავშირებულ დაწესებულებებთან, სკოლებთან, მომსახურებებსა და საწარმოებთან მიმართავს.

## ოთხი საყრდენი

- **განათლება:** იპოვეთ სკოლები, უნივერსიტეტები, კურსები და მთელი სიცოცხლის განმავლობაში სწავლის შესაძლებლობები.
- **საჯარო მმართველობა:** იპოვეთ სამინისტროები, საჯარო დაწესებულებები, კომუნალური და მოქალაქეთა მომსახურებები.
- **ბიზნესი:** უფასო ხელსაწყოები ბიზნესის დასაწყებად, სამართავად და გასაზრდელად.
- **BRASA:** ქვეყანაზე მორგებული საჯარო შესასვლელი, რომელიც მთელ სისტემას აერთიანებს.

## შექმნილია ქვეყნების მიხედვით

BRASA თითოეული მხარდაჭერილი ქვეყნისთვის ცალკე გვერდს ინახავს. ყველა გვერდი იყენებს საერთო გლობალურ დიზაინს და უკავშირდება შესაბამისი ქვეყნის რეალურ სახელმწიფო დაწესებულებებს, საგანმანათლებლო რესურსებსა და მომსახურებებს.

## ენობრივი ხელმისაწვდომობა

ინგლისური BRASA-ს შენარჩუნებული წყაროს ენაა. ვიზიტორებს შეუძლიათ გამოიყენონ ლოკალიზებული ვერსია, ხოლო რედაქტორები მუშაობას იმავე ინგლისური სტანდარტით აგრძელებენ. თითოეული გამოქვეყნებული თარგმანი იღებს საკუთარ მისამართს, ენობრივ მეტამონაცემებს, განხილვის სტატუსსა და ინგლისურ ვერსიაზე ბმულს.
