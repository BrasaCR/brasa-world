# BRASA 世界

**一个连接教育、政府服务、商业与公共透明度的系统，为每一位公民而建。**

[访问 BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [政府服务](https://brasagovernment.net/) · [商业](https://brasa.business/)

BRASA 将公共知识、公民服务、教育与商业连接起来，同时保留驱动全球系统的英文源内容。各国页面会把访客引导到与其居住地相关的机构、学校、服务和企业。

## 四大支柱

- **教育：**查找学校、大学、课程和终身学习机会。
- **政府服务：**访问各部委、公共机构、公用事业机构和公民服务。
- **商业：**帮助公民创办、经营和发展企业的免费工具。
- **BRASA：**根据国家定制的公共入口，连接整个系统。

## 逐国建设

BRASA 为每个受支持的国家维护独立的国家页面。每个页面采用共同的全球设计，并链接到该国真实的政府机构、教育资源和服务。

## 语言访问

英语是 BRASA 持续维护的源语言。访客可以使用本地化版本，编辑人员则继续按照同一英文标准工作。每个已发布的翻译都有独立地址、语言元数据、审核状态以及英文版本链接。

## 从这里开始

访问 [brasa.world](https://brasa.world/)，选择您的国家、语言或支柱。

## 参与贡献

帮助核实国家信息、审核翻译、报告过期公共链接或改善无障碍体验。准确性和有用的本地信息比翻译数量更重要。

## 今天的BRASA

BRASA现已将198个国家目的地与教育、政府和商业连接起来。BRASA Business包含12个互联领域：销售与收据、CRM、库存、人员与培训、工资与银行、时间管理、家庭支持、法律事务、政府表格、报告以及共享工作空间。系统还包括开放账本、引导式工作流程和离线连续运行。

BRASA Financials已从395条记录中整理出385种支付系统，涵盖161个国家或多国市场描述以及216种支付类型，包括移动支付、即时转账、QR、电子钱包、现金网络、汇款、开放银行、本地卡系统和USSD。

被收录不代表已经启用。资金由持牌服务商转移；每种方式都必须经过国家与官方来源核验、许可审查、技术集成、结算测试和生产批准。BRASA把经过核验的选项连接到收据、对账和开放账本。
