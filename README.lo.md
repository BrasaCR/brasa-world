# BRASA World

**ໜຶ່ງລະບົບເຊື່ອມຕໍ່ສຳລັບການສຶກສາ, ລັດຖະບານ, ທຸລະກິດ, ແລະຄວາມໂປ່ງໃສສາທາລະນະ—ສ້າງຂຶ້ນສຳລັບພົນລະເມືອງທຸກຄົນ.**

[ຢ້ຽມຢາມ BRASA World](https://brasa.world/) · [ການສຶກສາ](https://brasa.education/) · [ລັດຖະບານ](https://brasagovernment.net/) · [ທຸລະກິດ](https://brasa.business/)

BRASA ເຊື່ອມຕໍ່ຄວາມຮູ້ສາທາລະນະ, ການບໍລິການພົນລະເມືອງ, ການສຶກສາ, ແລະການຄ້າໂດຍບໍ່ມີການປ່ຽນແປງແຫຼ່ງພາສາອັງກິດທີ່ມີອໍານາດໃນລະບົບທົ່ວໂລກ. ຫນ້າປະເທດແນະນໍາຜູ້ເຂົ້າຊົມແຕ່ລະຄົນໄປຫາສະຖາບັນ, ໂຮງຮຽນ, ການບໍລິການ, ແລະທຸລະກິດທີ່ກ່ຽວຂ້ອງກັບບ່ອນທີ່ພວກເຂົາອາໄສຢູ່.

## ສີ່ເສົາ

- ** ການສຶກສາ: ** ຊອກຫາໂຮງຮຽນ, ມະຫາວິທະຍາໄລ, ຫຼັກສູດ, ແລະການຮຽນຮູ້ຕະຫຼອດຊີວິດ.
- ** ລັດ​ຖະ​ບານ​: ** ທ່ອງ​ໄປ​ຫາ​ກະ​ຊວງ​, ສະ​ຖາ​ບັນ​ສາ​ທາ​ລະ​ນະ​, ສາ​ທາ​ລະ​ນະ​ສຸກ​, ແລະ​ການ​ບໍ​ລິ​ການ​ພົນ​ລະ​ເມືອງ​.
- ** ທຸ​ລະ​ກິດ​: ** ເຄື່ອງ​ມື​ຟຣີ​ສໍາ​ລັບ​ພົນ​ລະ​ເມືອງ​ທີ່​ຈະ​ເລີ່ມ​ຕົ້ນ​, ການ​ດໍາ​ເນີນ​ງານ​, ແລະ​ຂະ​ຫຍາຍ​ຕົວ​ທຸ​ລະ​ກິດ​.
- **BRASA:** ທາງເຂົ້າສາທາລະນະທີ່ຮູ້ຈັກປະເທດທີ່ເຊື່ອມຕໍ່ລະບົບຄົບຊຸດ.

## ປະເທດທີ່ສ້າງຂຶ້ນໂດຍປະເທດ

BRASA ຮັກສາຫນ້າປະເທດສໍາລັບທຸກໆປະເທດທີ່ສະຫນັບສະຫນູນ. ແຕ່ລະຫນ້າໃຊ້ການອອກແບບທົ່ວໂລກຮ່ວມກັນໃນຂະນະທີ່ເຊື່ອມຕໍ່ກັບສະຖາບັນລັດຖະບານທີ່ແທ້ຈິງຂອງປະເທດນັ້ນ, ຊັບພະຍາກອນການສຶກສາ, ແລະການບໍລິການ.

## ການເຂົ້າເຖິງພາສາ

ພາສາອັງກິດແມ່ນພາສາຕົ້ນສະບັບທີ່ຮັກສາໄວ້ຂອງ BRASA. ນັກທ່ອງທ່ຽວສາມາດໃຊ້ສະບັບພາສາທ້ອງຖິ່ນໃນຂະນະທີ່ບັນນາທິການສືບຕໍ່ເຮັດວຽກຈາກມາດຕະຖານພາສາອັງກິດດຽວກັນ. ການແປທີ່ເຜີຍແຜ່ໄດ້ຮັບ URL ຂອງຕົນເອງ, metadata ພາສາ, ສະຖານະການທົບທວນຄືນ, ແລະເຊື່ອມຕໍ່ກັບຄືນໄປບ່ອນພາສາອັງກິດ.

## ເລີ່ມທີ່ນີ້

ຢ້ຽມຢາມ [brasa.world](https://brasa.world/) ແລະເລືອກປະເທດ, ພາສາ, ຫຼືເສົາຫຼັກຂອງເຈົ້າ.

## ປະກອບສ່ວນ

ຊ່ວຍຢັ້ງຢືນປະເທດ, ກວດເບິ່ງການແປ, ລາຍງານການເຊື່ອມຕໍ່ສາທາລະນະທີ່ລ້າສະໄຫມ, ຫຼືປັບປຸງການເຂົ້າຫາ. ຄວາມຖືກຕ້ອງແລະຂໍ້ມູນທ້ອງຖິ່ນທີ່ເປັນປະໂຫຍດແມ່ນມາກ່ອນປະລິມານການແປ.
